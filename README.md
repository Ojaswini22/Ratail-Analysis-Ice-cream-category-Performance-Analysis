Business Problem
Analyze retail sales performance to identify opportunities in assortment, pricing, shelf placement, and distribution

Key Insights

Rocky Road has the highest sales velocity but only ~20% distribution.
Rainbow Sherbet is the category leader.
Root Beer Float underperforms despite prime shelf placement.
Unicorn Sparkle is affected by limited-time availability.

Business Recommendations

Expand Rocky Road distribution.
Convert Unicorn Sparkle to a year-round product.
Reevaluate Root Beer Float assortment.
Optimize shelf placement using velocity data.
